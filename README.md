## 📖 About The Project

**Alisher Mebel** is a modern, responsive, and beautifully designed landing page for a furniture store. Built with core web technologies, it provides a smooth user experience for browsing furniture collections.

### ✨ Features
- **Responsive Design:** Looks great on desktops, tablets, and mobile devices.
- **Modern UI/UX:** Clean and attractive interface.
- **Fast Performance:** Lightweight and optimized.

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites
You only need a web browser to run this project!

### Installation
1. Clone the repo
   ```sh
   git clone https://github.com/abdusharipovboburmirzo5-oss/Alisher-mebel.git
   ```
2. Open `index.html` in your favorite browser.
